# Anji Zhu — Academic Portfolio

A responsive single-page academic portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

Install Node.js 20.19+ (or 22.12+) and run:

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The optimized deployable site is generated in `dist/`.

## Deploy

This is ready for any static host. Set these commands in Vercel, Netlify, Cloudflare Pages, or GitHub Pages:

- Build command: `npm run build`
- Publish directory: `dist`

Before publishing, replace the sample name, affiliation, contact address, social links, CV download target, course details, and publication links in `src/App.tsx`.
